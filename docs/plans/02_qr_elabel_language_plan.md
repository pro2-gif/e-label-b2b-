# 제품 선택 방식 변경 및 다국어(영문/국문) 지원 계획 (02_qr_elabel_language_plan)

## 목표
첫 화면에서 모든 제품이 나열되는 방식 대신, **원하는 제품을 검색하거나 드롭다운으로 선택**할 수 있도록 변경합니다. 또한, e-라벨 상세 페이지에서 **국문/영문 버전을 선택**하여 볼 수 있는 기능을 추가합니다.

## 핵심 변경 사항
1. **첫 화면 (ProductList) UI 개편**:
   - 화면에 진입하면 모든 QR이 보이는 것이 아니라, **"제품 선택" 드롭다운(Select 박스)**이 나타납니다.
   - 제품을 선택하면, 그 아래에 해당 제품의 QR 코드 1개만 깔끔하게 표시됩니다.
2. **다국어(국/영문) 지원 (ProductDetail)**:
   - QR 코드를 스캔하여 들어간 e-라벨 상세 화면 상단에 **[국문] / [ENG] 버튼**을 추가합니다.
   - 버튼을 누르면 화면 내용이 해당 언어에 맞게 부드럽게 전환됩니다.
3. **JT 디자인 시스템 적용**:
   - 셀렉트 박스와 토글 버튼 모두 기존에 설정한 JT 디자인 시스템 토큰(Charcoal, Blue 포인트)을 적용하여 세련되게 만듭니다.

## 사용자 확인 필요 사항 (오픈 퀘스천)
앱이 영어와 한국어를 구분해서 보여주려면, 스프레드시트 안에 영어 데이터가 어떻게 들어있는지 알아야 합니다.

**질문:** 구글 시트에 **영문 데이터는 어떤 식**으로 저장되어 있나요?
- **옵션 A**: 같은 시트 안에 컬럼(열) 이름이 다르게 있나요? (예: "제품명(국문)", "제품명(영문)")
- **옵션 B**: 아예 영문 전용 시트(탭)가 따로 있나요? (예: 아래쪽 탭에 "Sheet1", "Sheet2(영문)" 등)
- **옵션 C**: 아직 영문 데이터는 시트에 없고 기능만 먼저 만들어두면 되나요? (또는 앱 자체적으로 번역을 해야 하나요?)

## 진행 단계 (Step-by-Step)
1. 답변을 바탕으로 구글 시트 연동 모듈(`googleSheetService.js`)을 다국어 지원에 맞게 수정합니다.
2. 첫 화면(`ProductList.jsx`)의 UI를 전체 목록 형태에서 "제품 선택 및 단일 QR 표시" 형태로 바꿉니다.
3. 상세 화면(`ProductDetail.jsx`)에 언어 선택 탭(버튼)을 추가하고, 선택된 언어에 맞는 데이터를 렌더링하도록 코드를 수정합니다.
4. 사용자(수인님)에게 변경된 화면을 확인받습니다.
